# Android オフライン版

Web版と同じ637問、8問の市政知識五択、6科目の教材を同梱する独立アプリです。Web版のサーバーとDBには接続せず、履歴を端末内のSQLiteに保存します。Android 8.0以上を対象とします。

## APKのビルド

GitHub Actionsの「Android offline APK」→ 成功した実行 → `examapp-offline-android` をダウンロードしてZIPを展開します。中の `app-debug.apk` をAndroid端末で開き、ファイルを開いたアプリに対して「この提供元を許可」を設定し、インストールしてください。

このAPKは検証用のdebug署名です。次のビルドでは署名が変わる可能性があるため、更新前に必ずJSONバックアップを保存してください。署名が異なる場合、旧版をアンインストールして新しいAPKをインストールし、バックアップを取り込みます。継続的な上書き更新には、専用の署名鍵をGitHub Secretsで管理するreleaseビルドへの切り替えが必要です。

ローカルではJDK17、Gradle8.9、Android SDK35を用意して、リポジトリルートから次を実行します。

```sh
node --test mobile/web/core.test.cjs
python3 mobile/build_assets.py
cd mobile/android
gradle :app:assembleDebug :app:lintDebug
```

## 回答履歴の移行

アプリのホームまたは「設定」から「CSV・バックアップを取り込む」を押し、Web版で書き出したCSVを選択します。追加件数を確認して取り込みます。問題の `sourceItemKey` と回答日時で重複を検出するため、同じCSVを取り込み直しても二重計上しません。不明な問題IDや不正な値がある場合は全体を取り込まず、既存履歴を保持します。

CSVから正誤、迷った、回答日時、回答時間を引き継ぎます。選んだ○×自体はCSVに含まれません。復習予定・連続正解・習熟状態・正答率は日時順の履歴から再計算します。Web版の試験日や復習設定はCSVに含まれないので、試験日は「設定」で再設定してください。

## 保存とバックアップ

回答保存はSQLiteへの書き込み成功後に画面を進めます。演習途中も保存し、再起動後に再開できます。「設定」のJSONバックアップは○×・五択を含む全回答履歴と試験日を保存します。CSVも出力できます。アンインストール・端末のアプリデータ消去前にはJSONバックアップを保存してください。自動クラウド同期はありません。

## 機能と検証範囲

通常演習、科目・未回答・前回誤答・正答率70%未満・前回迷った・復習対象による絞り込み、全問選択、ランダム順、今日の復習、高速周回、五択演習、教材検索、科目別成績、バックアップ・履歴取り込みに対応します。Web版とは画面構成が異なります。履歴は互いに同期されません。五択の既存ブラウザー内履歴は、今回のWeb版CSVに含まれない場合は移行されません。

ネットワーク権限を持たず、WebViewは同梱ファイルだけを表示します。教材中の外部リンクは表示用の文字として扱います。APKのビルド・lintに加えて、インストール後はAndroid実機でCSV取り込み、機内モードでの演習、再起動後の履歴・途中演習保持、JSON復元を確認してください。
