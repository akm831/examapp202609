# 市政知識問題文の見直し（2026-10-02）

市政知識の○×110問を、問題文だけで施策・年度・問われる事実が分かる文章へ改稿した。略記、主語の欠落、教材の整理方法を問う表現、無関係な施策を詰め込んだ文章を解消した。五択8問も確認したが、既に具体的な施策を説明する形式であるため、今回の改稿対象には含めていない。

問題ID・sourceItemKey・正誤は維持し、他科目483問には変更を加えていない。原本教材を編集せず、`content/questions/shisei-rewrites.txt` と `tools/shisei_rewrites.py` を改稿原稿とする。`build_study_items.py` が再生成時にも改稿を適用する。

`data/shisei_rewrites.json` により、DBの再seed前でも通常演習・高速周回・回答フィードバック・回答ログ出力へ修正文と解説を適用する。DBの正誤と改稿データの正誤が一致しない場合は適用しない。採点処理は従来どおりDBの正誤を用いる。既に開いている演習画面は再読み込みが必要。

2026-10-02に改稿対象110問を札幌市の公式資料と照合し、財政推計の項目名、計画の正式名称、制度の対象条件、定数と人数の区別等を修正した。確認範囲・根拠資料・変更点は [公式資料照合記録](SHISEI_OFFICIAL_AUDIT.md) に記載した。教材基準日は2026-09-09のまま、ヒグマ一部改定などの時点指定も維持し、改定後の状態を解説に補足した。
