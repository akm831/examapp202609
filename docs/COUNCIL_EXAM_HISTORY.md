各対応区分は重複するため、足し合わせない。「対応あり」は同文、同論点、関連条文のいずれかを確認した問題数。

- 同文：空白・句読点等を除いた問題文の一致。DBの正誤は現在の採点に使用しない。
- 同論点：追加20問のうち14問について参照行を個別に確認。対応行は `content/questions/council-supplement.json` に保持する。既存問題には自動で同論点の判定を付けない。
- 関連条文：解説の参照条文とDBの根拠条文が一致。条の枝番号を区別し、施行令は法律本体に混ぜない。項・号単位の一致ではなく、別の論点も含む。
- 未確認：今回の照合で対応を確認できない状態。未出題とは断定しない。

表示する肢数はDB収録行数。複数年度をまとめた行も1肢とし、年度数は重複を除く。五択問題数・出題確率・網羅的な過去問出題回数ではない。年度はDBの表記で、公開過去問との年度差があるため公式年度として扱わない。参照行と年度を表示し追跡できるようにする。

## 再生成・反映

`python tools/import_past_exam_db.py <添付Excelのパス>` で抽出し、`python tools/build_study_items.py` で問題・実績データを再生成する。

出題実績はアプリ同梱データから既存IDに付与する。新20問を本番の出題対象に加えるには、コード反映に加えて対象DBに `npm run db:deploy` を実行する。seedは既存IDへのupsertで、回答履歴を削除しない。今回の作業環境には本番DB接続設定がなく、本番反映は実施していない。
