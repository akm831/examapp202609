# 市政知識テキスト

ホームの「テキストを読む」から `/texts/shisei` へ移動する。改訂版全文をテーマ別に収録し、目次・本文検索・3段階の文字サイズを提供する。重要条件は本文に表示し、詳細と全20問の全肢解説は折りたたむ。

○×演習（今日の復習・高速周回を含む）の解説、および本番形式の各肢解説から読書ダイアログを開く。明示的な施策名が一致すると対応本文を表示し、未知の過去テーマは目次を表示する。ダイアログの閉じる操作・Escapeで演習に戻り、演習コンポーネントをアンマウントしないため回答と迷った状態を保持する。端末保存・DB・復習計算は変更しない。

原本: `content/handbooks/shisei.md`。更新後に `python3 tools/build_handbook.py` を実行して2つのJSONを再生成する。Python標準ライブラリのみ使用。Markdownの対象機能は見出し、段落、強調、HTTPSリンク、リスト、表、引用、水平線、details/summary。任意HTMLはエスケープし、ユーザー入力のHTMLは描画しない。新しいMarkdown機能を加える場合はコンパイラを拡張する。

本文の改訂日と各事実の対象時点・確認日は異なる。アプリへ同梱したことは全項目の公式再監査を意味しない。本文に書かれた未確認・推定の制約をそのまま表示する。

教材の新規五択は閲覧用の確認問題で、解説を開いて自己確認する。既存の本番形式演習への採点データ追加や回答ログ保存は行わない。
