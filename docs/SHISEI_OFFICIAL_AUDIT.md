# 市政知識の公式資料照合（2026-10-02）

対象は今回改稿した○×110問（22グループ×5問）の問題文・解説・出題文脈。誤答用の記述については、公式資料との相違が解説で正しく説明されているかを確認した。五択8問は今回の公式資料照合の対象外。教材基準日2026-09-09および問題文中の時点指定を維持する。

## 修正した点

- q04:4：令和21年度のピーク項目を「建設債の元利償還金」から「建設債残高」に訂正。一般会計市債残高は令和15年度、建設事業費は令和11年度、建設事業の実質負担は令和21年度。財政改善策を行わない場合の試算であることを解説に補足。
- q14、q18、分野横断：正式名称を「第3次都心まちづくり計画」「第2次都心まちづくり計画」に訂正。5つの軸のうち4つは骨格軸、東4丁目線は展開軸であることも本書47ページで確認。
- q17：火葬・墓地の計画を「第2次札幌市火葬場・墓地に関する運営計画」と特定。基本構想や第1次計画と混同しないようにした。
- q21：「総職員数」を「総職員定数」に訂正。22,638人は実在籍人数ではなく定数の数値。
- q09:5：受診の目安ナビの対象に「札幌市内に住む」を追加。
- q07：加算対象の「低所得等世帯」を「住民税非課税世帯」に明確化。
- q01：特別会計集計から公債会計を除く旨を補足。億円の金額は資料の丸め表記に従う。
- q02：一般会計建設事業費の15.7％増は、前年度補正予算の前倒し計上分を除く比較であることを補足。
- q05:1：市税分と道税を含む合計額を区別し、誤答の金額がどちらにも一致しないことを説明。
- q06:4：令和7年度の利用世帯には、利用要件に変更がなければ継続利用できる扱いがある旨を追記。
- q12:2、q18:5：9月3日時点の判定根拠として9月1日の市長記者会見を確認。現時点では2026年9月に一部改定済みである旨を追記。
- q17:5：国の水道行政の移管の解説を水道整備・管理行政と水質基準等に分けて表現。q18:1の不要な2040年に関する説明を削除。

今回の照合範囲では、修正後の問題文・解説と参照した公式資料に未解消の矛盾は見つからなかった。ただし、将来の制度改定・予測変更まで保証するものではない。問題ID、sourceItemKey、正誤、採点処理は変更していない。
