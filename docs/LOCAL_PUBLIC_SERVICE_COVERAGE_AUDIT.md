# 地方公務員法の不足論点点検（2026-10-03）

既存192問と過去問DB602収録行を点検した。主要分野は収録されているが、条文内の細目に不足がある。単純な条番号一致を「論点収録済み」とは扱わない。アプリへの問題追加・既存問題変更・pushは行っていない。

## 判定方法

「直接問う問題なし」は、その論点を独立して判断する既存問題を確認できなかったもの。「部分収録」は周辺論点や一般原則は収録されているが、過去問の問い分けが不足するもの。問題数や科目全体の対応率から試験範囲の網羅率は推定しない。

実績はDBの年度表記と収録行数。複数年度をまとめた行は1肢、年度数は重複除外。各グループは重複し得るため合算しない。五択問題数・独立した出題回数ではない。過去問DBの正誤は現行法の採点根拠として再利用していない。

## 追加を急がなくてよい分野

分限処分の種類・事由、懲戒の種類・併科禁止・執行猶予、定年制度と近年の定年関連過去問、研修の主体・外部研修、措置要求の主体（条件付・臨時・退職者・職員団体）と管理運営事項、政治的行為の基本規制・争議行為については既に多くの問題がある。ただし分野内の全細目が網羅されているという意味ではない。

## 優先順位の提案

まず20～25問程度を、給与支払・報告勧告、職員団体の登録・協定・交渉、条件付等の審査請求適用除外、公開口頭審理・裁決前置、無報酬の営利企業役員から補完する。現行条文で確認できる問題を先行する。職務命令の効力、秘密の実質的範囲などの解釈論は行政実例・判例の原典確認後に別途補完する。20～25問は作成量の提案で、不足論点数を表す数字ではない。
