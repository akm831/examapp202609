法令基準日：2026年4月1日

## このテキストの使い方

このテキストは、地方自治法の現行標準20問を骨格として、重要な不足論点の補完6問を加え、1ファイルを順番に反復すれば試験範囲の主要論点を復習できるように再構成した総合学習用正本である。

**標準問題 → 5肢解説 → 関連する補完問題・比較メモ又は実過去問 → 次の標準問題**

- 標準20問の問題文・正答・解説は、既存final版を実質変更せず収録し、学習上の論点のまとまりに沿って再配置している。
- 正誤基準は2026年4月1日。試験範囲は地方自治法第2編第3章、第5章、第6章、第7章（第4節地域自治区を除く）、第9章、第10章。第9章は関連する地方自治法施行令を含む。
- 札幌市実過去問は、標準問題だけでは具体的適用・近年の札幌市型出題を十分に反復できない場合だけ追加した。同じ知識の単純反復になる問題は追加していない。
- 公開PDFで公式正答が確認できる問題は公式資料を優先する。DBの正誤ラベルと公式正答が矛盾する場合も公式資料を採用する。
- 【要確認】は、公開PDFによりその肢の正誤自体は確認できても、DB解説が依拠する行政実例・判例等の原典を今回の追加問題用に再確認できていない箇所を示す。確定暗記事項として理由付けを広げない。
- 過去問当時と2026年4月1日基準で正誤が変わる問題は、今回採用した追加問題にはない。監査段階で法改正影響のある旧問は追加対象から外した。

## I 住民・直接請求

## 標準問題1

地方自治法に定める直接請求に関する次の記述のうち、最も妥当なものはどれか。

1. 選挙権を有する者は、その総数の100分の1以上の者の連署をもって、その代表者から普通地方公共団体の長に対し、条例の制定又は改廃を請求することができる。
2. 条例の制定又は改廃の請求は、地方税の賦課徴収並びに分担金、使用料及び手数料の徴収に関する条例についても行うことができる。
3. 選挙権を有する者は、その総数の50分の1以上の者の連署をもって、その代表者から普通地方公共団体の長に対し、当該普通地方公共団体の事務の執行に関する監査を請求することができる。
4. 議会の解散を請求する場合には、法定数以上の選挙権を有する者の連署をもって、その代表者から当該普通地方公共団体の議会に対して請求しなければならない。
5. 条例の制定又は改廃の請求を受理したときは、普通地方公共団体の長は、請求を受理した日から20日以内に議会を招集し、意見を付けてこれを議会に付議し、その結果を代表者に通知するとともに公表しなければならない。

### 正答・正誤解説
**正答：5**
1. **×**　条例制定改廃請求は選挙権を有する者の総数の50分の1以上の連署を要する。〔74条〕
2. **×**　地方税の賦課徴収等に関する条例は対象から除かれる。〔74条〕
3. **×**　事務監査請求の請求先は監査委員である。〔75条〕
4. **×**　議会解散請求の請求先は選挙管理委員会である。〔76条以下〕
5. **○**　長は受理日から20日以内に議会を招集し、意見を付けて付議し、結果を代表者に通知するとともに公表しなければならない。〔74条3項〕

## II 議会

## 標準問題2

普通地方公共団体の議会の委員会に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体の議会は、条例で常任委員会、議会運営委員会及び特別委員会を置かなければならず、これらの委員会を置かないことはできない。
2. 常任委員会は、その部門に属する当該普通地方公共団体の事務に関する調査を行い、議案、請願等を審査するが、議会運営委員会は、議会の運営に関する事項について調査を行うにとどまり、議案、請願等を審査することはできない。
3. 常任委員会は、その部門に属する当該普通地方公共団体の事務に関する調査を行い、議案、請願等を審査するものとされている。
4. 委員会は、議会の議決すべき事件のうち、その部門に属する当該普通地方公共団体の事務に関するものについて議会に議案を提出することができ、予算についても議案を提出することができる。
5. 特別委員会は、委員長が選定した事件を審査するものとされており、議会の議決により事件を付議されることを要しない。

### 正答・正誤解説
**正答：3**
1. **×**　議会は条例で常任委員会、議会運営委員会及び特別委員会を置くことができる。設置義務ではない。〔109条1項〕
2. **×**　議会運営委員会も議案、請願等を審査する。〔109条3項〕
3. **○**　常任委員会は、その部門に属する事務を調査し、議案、請願等を審査する。〔109条2項〕
4. **×**　委員会の議案提出権から予算は除かれる。〔109条6項〕
5. **×**　特別委員会は議会の議決により付議された事件を審査する。〔109条4項〕

## 標準問題3

地方自治法に定める普通地方公共団体の議会の権限及び調査に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体の議会は、条例を設け又は改廃することについては議決しなければならないが、予算を定めることについては議決を要しない。
2. 普通地方公共団体の議会は、その事務に関する監査を監査委員に求めることはできるが、監査結果に関する報告を請求することはできない。
3. 普通地方公共団体の議会は、法定の除外事務を除き、当該普通地方公共団体の事務に関する調査を行うことができ、その調査のため特に必要があると認めるときは、選挙人その他の関係人の出頭及び証言並びに記録の提出を請求することができる。
4. 普通地方公共団体の議会は、当該普通地方公共団体の公益に関する事件につき、意見書を国会に提出することはできるが、関係行政庁に提出することはできない。
5. 地方自治法第100条の調査において証言を請求する場合には、地方自治法に特別の定めがあるものを除くほか、刑事訴訟に関する法令のうち証人の尋問に関する規定が準用される。

### 正答・正誤解説
**正答：3**
1. **×**　予算を定めることも議会の議決事件である。〔96条〕
2. **×**　議会は監査結果に関する報告も請求できる。〔98条2項〕
3. **○**　議会は法定の除外事務を除き事務に関する調査を行い、必要があると認めるときは関係人の出頭・証言・記録提出を請求できる。〔100条1項〕
4. **×**　意見書は国会又は関係行政庁に提出できる。〔99条〕
5. **×**　準用されるのは民事訴訟に関する法令の証人尋問規定である。〔100条2項〕

## 標準問題4

地方自治法に定める普通地方公共団体の議会の会議運営に関する次の記述のうち、最も妥当なものはどれか。

1. 議会の会議は公開するのが原則であるが、議長又は議員3人以上の発議により、出席議員の3分の2以上の多数で議決したときは、秘密会を開くことができる。
2. 議長は、議会運営委員会の議決を経て付議事件を示した場合には、普通地方公共団体の長に臨時会の招集を請求することなく、自ら臨時会を招集することができる。
3. 議会は、地方自治法に定める例外の場合を除き、議員定数の3分の1以上の議員が出席すれば会議を開くことができる。
4. 議案に対する修正の動議を議題とするには、議員定数の6分の1以上の者の発議を要する。
5. 会期中に議決に至らなかった事件は、特別の議決を要することなく後会に継続する。

### 正答・正誤解説
**正答：1**
1. **○**　会議は公開が原則だが、議長又は議員3人以上の発議により、出席議員の3分の2以上で秘密会を開くことができる。〔115条〕
2. **×**　議長は長に臨時会の招集を請求できるのであり、自ら招集するものではない。〔101条〕
3. **×**　原則として議員定数の半数以上の出席を要する。〔113条〕
4. **×**　修正動議は議員定数の12分の1以上の発議を要する。〔115条の2〕
5. **×**　会期中に議決に至らなかった事件は後会に継続しない。〔119条〕

## III 長・執行機関

## 標準問題5

地方自治法に定める普通地方公共団体の長に対する不信任の議決等に関する次の記述のうち、最も妥当なものはどれか。

1. 議会が長の不信任の議決をする場合には、議員数の過半数の者が出席し、その出席議員の3分の2以上の者の同意があれば足りる。
2. 議会において長の不信任の議決がされた場合、長は、その通知を受けた日から10日以内に議会を解散しなければならない。
3. 長が不信任の議決を受けて議会を解散した後、初めて招集された議会において再び不信任の議決がされ、議長からその旨の通知があった場合には、長は、その通知を受けた日から10日以内であれば、再度議会を解散することができる。
4. 地方自治法第152条の規定により長の職務を代理する者は、長の不信任に関する地方自治法第178条第1項の「長」に含まれる。
5. 議会において長の不信任の議決がされ、議長からその旨の通知を受けた場合において、長がその通知を受けた日から10日以内に議会を解散しないときは、長は、その期間が経過した日にその職を失う。

### 正答・正誤解説
**正答：5**
1. **×**　最初の不信任議決は、議員数の3分の2以上が出席し、その4分の3以上の同意を要する。〔178条〕
2. **×**　長は通知を受けた日から10日以内に議会を解散することができるのであり、解散義務ではない。〔178条〕
3. **×**　解散後初めて招集された議会で再び不信任議決があり通知されたとき、長は通知の日に職を失う。〔178条〕
4. **×**　行政実例（昭23.6.16）は、第178条第1項の「長」に職務代理者を含まないとしている。
5. **○**　最初の不信任議決の通知後10日以内に議会を解散しないとき、長はその期間経過日に職を失う。〔178条〕

## 補完問題1　副市町村長・長の退職

地方自治法に定める副市町村長等に関する次の記述のうち、最も妥当なものはどれか。

1. 市町村長が退職しようとするときは、退職しようとする日前10日までに、その旨を議会の議長に申し出なければならない。
2. 市町村には副市町村長を置くことが原則であるが、条例で置かないことができ、副市町村長の定数は条例で定める。
3. 副市町村長は任期中、議会の同意がなければ長が解職することはできない。
4. 普通地方公共団体の長の職務を代理している副市町村長が退職しようとするときは、議会の許可を受けなければならない。
5. 副市町村長は長を補佐し補助機関である職員の担任事務を監督するが、長の職務を代理することはできない。

### 正答・正誤解説
**正答：2**
1. **×**　市町村長は、原則として退職しようとする日前20日までに議会の議長へ申し出る。〔145条〕
2. **○**　市町村には副市町村長を置くが、条例で置かないことができ、定数も条例で定める。〔161条〕
3. **×**　副市町村長の任期は4年であるが、長は任期中でも解職できる。〔163条〕
4. **×**　長の職務を代理する副市町村長が退職しようとするときは、退職日の20日前までに議会の議長へ申し出る。議会の許可を要する制度ではない。〔165条〕
5. **×**　副市町村長は、別に定めるところにより長の職務を代理する。〔167条〕


### 関連メモ｜長の担任事務（149条）

長は予算の調製・執行、地方税の賦課徴収、分担金・使用料・加入金・手数料の徴収、財産の取得・管理・処分、会計の監督等を担任する。会計管理者の出納・決算事務（標準問題14）と主体を取り違えない。

## 標準問題6

普通地方公共団体の長と委員会又は委員との関係に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体の長は、その権限に属する事務の一部を、当該普通地方公共団体の委員会又は委員と協議して、当該委員会若しくは委員又はこれらの事務を補助する職員若しくはこれらの管理に属する機関に委任することができる。
2. 普通地方公共団体の長は、その権限に属する事務の一部を委員会又は委員の事務を補助する職員に補助執行させることはできるが、委員会又は委員に委任することはできない。
3. 普通地方公共団体の委員会又は委員は、その権限に属する事務の一部を、長の補助機関である職員に補助執行させることはできない。
4. 普通地方公共団体の委員会又は委員は、法律に特別の定めがない場合であっても、普通地方公共団体の予算を調製し、及びこれを執行する権限を有する。
5. 普通地方公共団体の長が、その権限に属する事務の一部を委員会又は委員の事務を補助する職員に委任する場合には、当該委員会又は委員との協議を要しない。

### 正答・正誤解説
**正答：1**
1. **○**　長は、委員会又は委員と協議して、その権限に属する事務の一部を委員会等に委任することができる。〔180条の2〕
2. **×**　委員会又は委員への委任も認められている。〔180条の2〕
3. **×**　委員会又は委員は、長と協議して長の補助機関である職員に補助執行させることができる。〔180条の7〕
4. **×**　法律に特別の定めがあるものを除き、委員会又は委員は予算を調製し執行する権限を有しない。〔180条の6〕
5. **×**　第180条の2による委任等には当該委員会又は委員との協議を要する。

### 比較メモ｜長の権限を補助機関の職員へ委任・臨時代理させる場合

- **153条1項**：長は、その権限に属する事務の一部を**補助機関である職員**に委任し、又はこれに**臨時に代理**させることができる。
- **180条の2**（本問）：長が**委員会・委員又はこれらの事務を補助する職員等**に事務の一部を委任・補助執行させる場合は、当該委員会・委員との**協議**を要する。委任先を補助機関の職員と行政委員会側の職員等とで取り違えない。

## 標準問題7

普通地方公共団体の執行機関の附属機関に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体は、法律又は規則の定めるところにより、執行機関の附属機関を置くことができる。
2. 普通地方公共団体は、要綱の定めるところにより、執行機関の附属機関として審議会又は調査会を置くことができる。
3. 普通地方公共団体は、法律又は条例の定めるところにより、議会の附属機関として審査会、審議会又は調査会を置くことができる。

5. 普通地方公共団体は、法律又は条例の定めるところにより、執行機関の附属機関として自治紛争処理委員、審査会、審議会、調査会その他の調停、審査、諮問又は調査のための機関を置くことができる。

### 正答・正誤解説
**正答：5**
1. **×**　附属機関を置く根拠は法律又は条例である。〔138条の4第3項〕
2. **×**　要綱ではなく法律又は条例の定めるところによる。〔138条の4第3項〕
3. **×**　同項が定めるのは執行機関の附属機関である。
4. **×**　審査会も掲げられている。
5. **○**　法律又は条例の定めるところにより、執行機関の附属機関として自治紛争処理委員、審査会、審議会、調査会その他の調停、審査、諮問又は調査のための機関を置くことができる。〔138条の4第3項〕

## 補完問題2　専門委員と附属機関

地方自治法に定める専門委員及び附属機関に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体は、常設又は臨時の専門委員を置くことができ、専門委員は専門の学識経験を有する者の中から長が選任し、非常勤とされる。
2. 専門委員を選任するには、必ず議会の同意を得なければならない。
3. 専門委員は、法律又は条例により置かれる審議会・調査会等と同じ合議制の附属機関である。
4. 同一事務について複数の専門委員を置いた場合は、当然に一つの合議制機関を構成する。
5. 執行機関の附属機関は、法律又は規則の定めるところにより設置することができる。

### 正答・正誤解説
**正答：1**
1. **○**　専門委員は常設又は臨時に置くことができ、専門の学識経験を有する者の中から長が選任し、非常勤とされる。〔174条〕
2. **×**　174条は議会同意を選任要件としていない。
3. **×**　専門委員は174条の個別制度であり、138条の4第3項の審査会・審議会・調査会等の附属機関とは区別する。
4. **×**　専門委員を複数置いたことだけで当然に合議制機関になるとの規定はない。

### 関連メモ｜附属機関の庶務（202条の3）

### 関連メモ｜歳入の督促と債権管理

- **231条・施行令154条1項**：歳入を収入するときは調定を行い、所属年度・歳入科目・納入すべき金額・納入義務者等に誤りがないかなどを確認する。納入通知の扱いは同令154条による。
- **231条の3第1・2項**：分担金・使用料・加入金・手数料・過料その他の歳入を納期限までに納付しない者があるとき、長は期限を指定して**督促しなければならない**。督促した場合、条例により手数料・延滞金を**徴収できる**。義務と裁量を区別する。
- **同条3項**：地方税の滞納処分の例による処分は、同項で定められた歳入及び要件に限る。未納の歳入を一律に強制徴収できるという扱いにはしない。
- **240条2・4項**：長は、同条の債権について政令に従い督促・強制執行その他保全・取立てに必要な措置をとる。ただし、4項に定める債権には2項等を適用しない。236条の時効と、240条の債権管理を分けて覚える。

2. 職員に対する損害賠償請求権は、地方自治法に規定する所定の要件を充たす事実があるだけで直ちに発生するものではなく、当該普通地方公共団体の長の賠償命令により、初めてその請求権が発生する。
3. 賠償責任の対象となる職員とは、現に当該普通地方公共団体に勤務する職員のことを指すことから、損害発生の原因行為をした当該職員が既に退職している場合には、当該賠償責任を負うことはない。
4. 資金前渡を受けた職員が、故意又は過失により保管する現金を亡失したときは、これによって生じた損害を賠償しなければならないが、物品を使用している職員が、当該物品を亡失し、又は損傷した場合は、その職員に故意又は重過失があったときに限り、損害を賠償しなければならない。
5. 長は、職員が当該普通地方公共団体に損害を与えたと認めるときは、その事実があるかどうかを監査し、賠償責任の有無及び賠償額を決定した上で、期限を定めて賠償を命じなければならない。

#### 応用問題の正答・正誤解説
**公式正答：4**

1. **×**　2人以上の職員が損害を生じさせた場合は、それぞれの職分に応じ、かつ、それぞれの行為が損害発生の原因となった程度に応じて賠償責任を負う。〔243条の2の8〕
2. **×【要確認】**　公式正答4により誤りであることは確認できる。DBには、所定要件を満たす事実があれば請求権は直ちに発生し、長の賠償命令で初めて発生するものではないとする判例解説があるが、今回その判例原典は再確認していない。なおDBのR6ラベルはこの肢を○としており、公式正答4と矛盾するため公式PDFを優先する。
3. **×【要確認】**　公式正答4により誤りであることは確認できる。DBは退職後又は死亡後でも賠償責任を免れ得ない旨を行政実例としているが、原典未再確認のため理由部分は【要確認】とする。
4. **○**　現金の亡失等は故意又は過失、物品の亡失・損傷は故意又は重大な過失が要件となる。〔243条の2の8第1項〕
5. **×**　監査及び賠償責任の有無・賠償額の決定は監査委員に求め、長はその決定に基づいて賠償を命ずる。〔243条の2の8第3項〕

## VIII 公の施設

## 標準問題20

地方自治法に定める公の施設に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体は、法律又はこれに基づく政令に特別の定めがある場合を除き、公の施設の設置及びその管理に関する事項を規則で定めなければならない。
2. 普通地方公共団体が公の施設の管理を指定管理者に行わせる場合、指定管理者の指定は期間を定めて行うものとされ、指定しようとするときは、あらかじめ当該普通地方公共団体の議会の議決を経なければならない。
3. 普通地方公共団体は、公の施設の設置目的を効果的に達成するため必要があると認めるときは、条例の定めるところにより、法人その他の団体だけでなく個人を指定管理者として指定することができる。
4. 指定管理者は、2会計年度ごとに、その管理する公の施設の管理の業務に関し事業報告書を作成し、当該公の施設を設置する普通地方公共団体に提出しなければならない。
5. 公の施設の利用料金は、指定管理者が管理する場合であっても、当該指定管理者の収入として収受させることはできず、普通地方公共団体の収入としなければならない。

### 正答・正誤解説
**正答：2**
1. **×**　公の施設の設置及び管理に関する事項は原則として条例で定める。〔244条の2第1項〕
2. **○**　指定管理者の指定は期間を定め、指定しようとするときはあらかじめ議会の議決を経る。〔244条の2第5・6項〕
3. **×**　指定対象は法人その他の団体であり、個人を指定する規定ではない。〔244条の2第3項〕
4. **×**　指定管理者は毎年度終了後に事業報告書を提出する。〔244条の2第7項〕
5. **×**　適当と認めるときは利用料金を指定管理者の収入として収受させることができる。〔244条の2第8項〕

### 応用問題｜札幌市実過去問 R8公開・公の施設

普通地方公共団体の公の施設に関する次の記述のうち、最も妥当なものはどれか。

1. 普通地方公共団体は、公の施設の管理を指定管理者に行わせる場合において、適当と認めるときは、指定管理者にその管理する公の施設の利用料金を当該指定管理者の収入として収受させることができるところ、この利用料金は、公益上必要があると認める場合を除き、長が定める。
2. 普通地方公共団体が、公の施設の管理を指定管理者に行わせた場合、当該指定管理者は、当該公の施設の清掃、警備等の個々の具体的な業務を第三者に委託することができるほか、長の許可があれば、管理に係る業務を一括して第三者に委託することもできる。
3. 地方自治法上の公の施設とは、不特定多数の者の利用を目的として、普通地方公共団体が整備し、及び運営する全ての施設をいうことから、当該普通地方公共団体の庁舎は、公の施設に該当する。
4. 普通地方公共団体は、住民が公の施設を利用することについて、不当な差別的取扱いをしてはならないが、住民ではないがその区域内に事務所を有するなど住民に準ずる地位にある者が公の施設を利用することについては、合理的な理由がなくても差別的取扱いをすることができる場合がある。
5. 普通地方公共団体が、公の施設の管理を指定管理者に行わせるには、指定管理者の指定の手続、指定管理者が行う管理の基準及び業務の範囲その他必要な事項を条例で定めなければならず、また、指定管理者の指定をしようとするときは、あらかじめ議会の議決を経なければならない。

#### 応用問題の正答・正誤解説
**公式正答：5**

1. **×**　利用料金は、条例の定めるところにより指定管理者が定め、あらかじめ普通地方公共団体の承認を受けなければならない。〔244条の2第9項〕
2. **×【要確認】**　公式正答5により誤りであることは確認できる。DB解説は平成15年7月17日通知を根拠に一括再委託を不可としているが、今回その通知原典を追加問題用に再確認していない。
3. **×【要確認】**　公式正答5により誤りであることは確認できる。庁舎を公の施設に含めないという具体的適用はDB解説だけでは原典が確認できないため、理由部分は【要確認】とする。
4. **×【要確認】**　公式正答5により誤りであることは確認できる。DBは、住民に準ずる地位にある者にも合理的理由のない差別的取扱いは許されない旨を行政実例としているが、原典未再確認のため理由部分は【要確認】とする。
5. **○**　指定管理者制度の必要事項は条例で定め、指定にはあらかじめ議会の議決を要する。〔244条の2第4・6項〕
